# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email [info@may.inc](mailto:info@may.inc?subject=S3%20viewer%20security). Reports
must include **S3 viewer** in the subject line. You can also use GitHub's
[private vulnerability reporting](../../security/advisories/new) on this repository.

Supported versions: the `main` branch and the latest release.

Please provide:

- a description of the issue and its impact,
- steps to reproduce (a proof of concept helps),
- any suggested fix.

## What to expect

- Acknowledgement within 3 business days.
- A fix or a mitigation plan within 90 days of the report.
- Coordinated disclosure: we ask that you keep the report private for up to
  90 days, and we will credit you in the fix unless you prefer otherwise.
